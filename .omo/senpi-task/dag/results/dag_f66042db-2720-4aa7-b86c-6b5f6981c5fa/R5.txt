### Implementation Summary

1. **GitHub Actions Matrix Workflow (`.github/workflows/rust-matrix.yml`)**:
   - Configured cross-platform CI matrix across:
     - macOS: `os: macos-latest`, `target: aarch64-apple-darwin`, `features: macos-host` (real feature defined in `erd-host/Cargo.toml`)
     - Linux: `os: ubuntu-latest`, `target: x86_64-unknown-linux-gnu`, `features: default`
     - Windows: `os: windows-latest`, `target: x86_64-pc-windows-msvc`, `features: default`
   - Steps per job:
     - Checkout repository (`actions/checkout@v4`)
     - Add Rust target via `rustup target add ${{ matrix.target }}`
     - Install FFmpeg build dependencies (`apt` packages on Ubuntu: `libasound2-dev`, `libavcodec-dev`, `libavformat-dev`, `libavutil-dev`, `libswscale-dev`, `libswresample-dev`, `libudev-dev`, `libva-dev`, `libwayland-dev`, `libx264-dev`, `pkg-config`; Chocolatey shared setup documented on Windows with `OPENSSL_STATIC=1`)
     - Build host binary: `cargo build -p erd-host --features ${{ matrix.features }} --release --target ${{ matrix.target }}`
     - Build workspace binaries: `cargo build --workspace --release --target ${{ matrix.target }}`
     - Run tests across workspace: `cargo test --workspace`
     - Stage and upload release binary artifacts (`erd-host`, `erd-client`, `tauri-shell`) via `actions/upload-artifact@v4`.

2. **Packaging Configs (`clients/rust/packaging/`)**:
   - `nsis/EclipticRD.nsi`: Bundles `erd-host.exe`, `erd-client.exe`, `tauri-shell.exe`, desktop/start menu shortcuts, uninstaller, and optional FFmpeg runtime DLLs with `README-FFMPEG.md`.
   - `nsis/README-FFMPEG.md`: Documents required Windows FFmpeg DLLs (`avcodec`, `avformat`, `avutil`, `swscale`, `swresample`), recommended bundle directory layout, and LGPL v2.1+/GPL compliance guidelines.
   - `install.sh`: Linux installer checking FFmpeg runtime library dependencies via `pkg-config` / `ldconfig` and CLI presence, installing binaries to `/usr/local/bin` (or custom `$DESTDIR`).
