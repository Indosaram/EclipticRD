### 3. Key Fixes Applied
- **UDP Ping Handling**: Prevented UDP timestamp ping packets from triggering unneeded blocking TCP control responses on every frame.
- **Client Receiver Threading**: Decoupled socket datagram reception from FFmpeg frame decoding via a bounded channel buffer.
- **Auto-Approve Automation**: Added `--auto-approve` flag support for non-interactive host sessions in headless VM test runners.
